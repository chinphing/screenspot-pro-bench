# 数据划分（splits/）

| 文件 | 条数 | 用途 | 允许调参 |
|---|---|---|---|
| `M1.json` | 20 | 开发/迭代 | ✅ |
| `M2.json` | 300 | 定成绩 | ❌ 冻结后跑 |
| `M3.json` | 1261 | 最终验收 | ❌ |

**合计 1581，三者互斥。**

完整规范（抽样方法、分布吻合度、评测协议）见 [`../docs/SPLITS.md`](../docs/SPLITS.md)。

## 复现

```bash
python3 scripts/make_splits.py            # 重新生成（种子 20261016）
python3 scripts/make_splits.py --verify   # 校验现有划分与算法一致
```

M1 的 20 个 id 硬编码在 `scripts/make_splits.py` 里（前序实验用的固定集合），
M2 由「一级=应用 / 二级=目标尺寸档」分层抽样得到，M3 是其余全部。

## ⚠️ 两条铁律

1. **划分一旦用于定成绩就不许再改。** 改种子等于换评测集，成绩不可比。
2. **在 M2 上看到成绩后不许回头调参。** 那样 M2 就变成训练集，成绩不再代表泛化能力——
   此时必须换 M3 报成绩。

## M1 的偏差（为什么不能拿 M1 成绩外推）

| 维度 | M1（20 条）| 全量（1581 条）|
|---|---|---|
| 目标长边中位 | **40px** | 63px |
| 小目标(<40px) 占比 | **50%** | 36% |

**→ M1 明显偏难。历史实验的 82% / 74% / 71% 都是 M1 上的，不能当全量成绩。**
